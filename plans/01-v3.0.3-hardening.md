**Mode:** manual (stop between phases)

Post-ship review of v3.0.3 turned up 22 concrete fixes across SSH refactor + installer + provisioner + CI. Two guiding principles:

1. **Onion rule.** Extra safety layers with no downside are keepers. Don't remove imperfect layers because of theoretical bypasses — fix the layer's docs to be honest, stack more layers on top.
2. **Fail loud, not silent.** Multiple items are "silent failure → user debugs for an hour" bugs. Every fix trades silence for a warn/error.
